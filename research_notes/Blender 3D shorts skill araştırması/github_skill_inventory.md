# GitHub / skill inventory: agent skills, plugins and MCP servers that make 3D vertical shorts in Blender (Zack D. Films–style explainers)

Method note: research date 2026-11-23. Star counts, last-push dates and SPDX licences come from the GitHub search API (`gh api search/repositories` / `search/code`; the per-repo endpoint `repos/{owner}/{repo}` was blocked in this session). READMEs and SKILL.md files were read through raw.githubusercontent.com. Where the README states a licence (e.g. "MIT") but GitHub's API reports NOASSERTION, both are given. About 40 repository queries and 15 code queries were run (terms included: blender shorts / reels / tiktok, zack d films, zackdfilms, 3d explainer blender, bpy video agent, blender mcp video, blender agent skills, anatomy blender animation, topic:blender + claude-code / agent-skills / mcp, plus SKILL.md code searches for blender+shorts, blender+reels, MPFB, LUFS, BodyParts3D, Z-Anatomy and "fresh critic").

## Q1. Which repos exist? Ranked inventory, with known repos checked and new ones added

### Takeaway
Only a handful of open-source projects actually render vertical explainer shorts in Blender from an agent. For **photoreal "what happens if" content with realistic humans and anatomy**, the closest match is **Hitid123/kylo-3d-shorts** (MPFB/MakeHuman people, X-ray anatomy twin, Poly Haven, −14 LUFS, a reference measurer). **goinsidemachines/blender-shorts-agent** is the most engineered and best-checked pipeline, but it targets mechanical subjects and adds no music. **nocodehack/make-short** has been deleted, but a vendored copy of its SKILL.md survives, and it has the best critic-agent design. Most "Zack D Films" repos are *not* Blender: they use three.js, Veo or other AI video, or prompts only. All candidates are new, low-star repos (0–200★) made between mid and late 2026, apart from the big MCP servers and general toolkits.

### Inferences
- No single repo combines photoreal humans, anatomy cutaways, a critic agent and pro post. The practical stack would be: **kylo-3d-shorts** for MPFB humans, X-ray and the reference measurer; **blender-shorts-agent** for checks, chunked renders and the mix; the **make-short** critic loop and reference measurement; and **mromidev/claude-blender-skills** for photoreal lighting and render-speed rules. Anatomy assets would come from human-models-mcp, anatomy-clips or Z-Anatomy.
- Activity is very recent (most repos were pushed in October–November 2026) and star counts are tiny, so maturity and maintenance risk are high. Deletions like make-short show it's worth forking or archiving what you depend on.
- Many repos marketed as "Zack D Films" are actually three.js or AI-video based. Their scripting and measurement material (meris01 corpus metrics, mromidev style bible) can still feed a Blender pipeline.

## Q2. Feature checklist per candidate

### Takeaway
Reference-video analysis exists in three projects (kylo's "reference measurer", make-short's "reference measure" and mixamo-llm-mocap's compare_reference). **None of them uses phase-correlation camera-motion analysis.** An independent critic or judge scoring stills appears explicitly only in make-short. −14 LUFS mastering is common (kylo, kinnuworks, TheFlatStory). Photoreal post (AgX, grain, bloom, vignette, motion blur) is barely documented anywhere; TheFlatStory names AgX and shutter-blurred whip-pans. Blender MCP is used by yoruuuchan, Molecular_Animation, mixamo-llm-mocap and axumweyane (its own MCP); most shorts pipelines instead run headless `blender -b -P`.

### Inferences
- Phase-correlation or optical-flow camera-motion analysis of reference videos was not found in any repo, either in README keyword scans or in a code search for "phase correlation reference video blender". It would be a novel addition.
- Explicit photoreal post-processing chains (AgX + film grain + bloom/glare + vignette + motion blur) aren't documented as a package in any shorts skill. TheFlatStory (AgX, shutter blur) and the EL4CTEO/blender-skills mood references come closest. kumikilongyeyo does bloom and lens blur in After Effects (paid).
- Paid dependencies are common: ElevenLabs (kylo, kinnuworks, TheFlatStory, make-short optional), MuAPI/Veo (Anil-matcha), Higgsfield (paullabs optional, J-StaR), After Effects (kumikilongyeyo). blender-shorts-agent (Kokoro/Chatterbox local TTS) and make-short (record your own voice plus local whisper) have fully free routes.

### Gaps
- Feature presence was judged from READMEs and SKILL.md only. Deeper files (references/, scripts/) were not read, so features like AgX, motion blur or OIDN denoising may exist without being mentioned there.
- I found no repo that packages ARKit-52 blendshape facial animation for shorts. kylo mentions MPFB facial expressions, and EL4CTEO/blender-skills mentions shape keys once.
- No repo published a measured render time per second of photoreal Cycles vertical footage for human characters.
